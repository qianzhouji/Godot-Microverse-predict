## 项目简介 {#项目简介}

这是一个基于**努力决策理论**和**边际价值定理(MVT)**的AI Agent模拟系统，用于探究**抑郁风险青少年**与**健康青少年**在动态社会情境中的认知机制差异。

通过构建虚拟校园环境，模拟学生在不同情境（课堂、食堂、体育馆等）中的行为决策过程，追踪抑郁症状的演化轨迹，为青少年心理健康干预提供理论依据。

------------------------------------------------------------------------

## 核心研究问题 {#核心研究问题}

**抑郁风险学生是否在努力导向决策中存在系统性偏差？**

具体而言： - 抑郁风险学生是否对**努力成本**过度敏感？ - 抑郁风险学生是否对**奖赏衰减**感知异常？ - 这些认知偏差如何影响其**情境选择**和**社交行为**？

------------------------------------------------------------------------

## 理论框架：边际价值定理 (MVT) {#理论框架边际价值定理-mvt}

### 客观收益函数（系统维护，Agent不可见）

```         
G(t) = (S/a)[1 - exp(-at)]
```

-   **S**: 初始收益率
-   **a**: 收益衰减率
-   **t**: 停留时间

### Agent感知与决策

```         
U(G) = G^α - β_effort × E
```

-   **α**: 收益敏感性（0\<α≤1）
-   **β_effort**: 努力敏感性（核心差异参数）
-   **E**: 努力成本

### 最优停留时间（MVT解析解）

```         
log(T) = log[ηS · log(S)] − log(ρbase) − βeffort · effort − ηa · log(a) + ε
```

**四个核心认知参数**: \| 参数 \| 符号 \| 健康Agent \| 抑郁Agent \| 功能 \| \|------\|------\|----------\|----------\|------\| \| 离开阈值 \| ρ_base \| 0.5-0.6 \| 0.3-0.4 \| 对环境平均奖赏率的估计 \| \| 初始奖赏感知权重 \| η_S \| 0.5 \| 0.4 \| 对初始丰富度的敏感度 \| \| 衰减率感知权重 \| η_a \| 0.5 \| 0.7 \| 对奖赏衰减的敏感度 \| \| **努力敏感性** \| **β_effort** \| **0.4** \| **0.8** \| **核心差异参数** \|

**个体差异**： \| 参数 \| 健康Agent \| 抑郁风险Agent \| \|------\|----------\|--------------\| \| 收益敏感性 α \| 0.8 \| 0.5-0.6 \| \| 努力敏感性 β_effort \| 0.4 \| **0.8** \| \| 离开阈值 ρ_base \| 0.5-0.6 \| **0.3-0.4** \| \| 初始奖赏感知权重 η_S \| 0.5 \| **0.4** \| \| 衰减率感知权重 η_a \| 0.5 \| **0.7** \|

**结果**：相同客观收益，抑郁Agent的主观效用显著降低；抑郁Agent倾向于提前离开（低ρ_base）、对初始奖赏不敏感（低η_S）、高估衰减速度（高η_a）

## 三层认知架构 {#三层认知架构}

### Layer 1: 客观现实（系统层）

-   **性质**: 物理存在，所有Agent共享相同客观参数
-   **内容**: 真实情境参数（S, a, E）、真实收益函数
-   **访问**: Agent不可见，通过RewardSystem间接获取奖赏

### Layer 2: 感知推断（认知层）

-   **性质**: 贝叶斯更新过程，个体差异显著
-   **机制**: 先验信念 → 体验采样 → 贝叶斯更新
-   **噪声**: 感知噪声极小（σ=2%），主要噪声在决策层

### Layer 3: 效用评估（决策层）

-   **性质**: 非线性效用计算，个体差异核心体现
-   **公式**: U(G) = G\^α - β_effort × E
-   **结果**: 计算最优停留时间T\*，驱动行为决策

## 核心功能 {#核心功能}

### 🤖 三类核心智能体 {#三类核心智能体}

#### 1. 抑郁风险学生智能体（观测对象）

-   **特征**: 高努力敏感性（β_effort ≈ 0.8），收益敏感性降低（α ≈ 0.5-0.6）
-   **追踪指标**: 每日PHQ-9自评、情境停留时间、社交互动频率
-   **行为表现**: 回避高努力情境（课堂发言、体育活动），偏好低努力情境（食堂、走廊）

#### 2. 健康学生智能体（环境群体）

-   **特征**: 正常认知参数（β_effort ≈ 0.4, α ≈ 0.8）
-   **功能**: 构成社会互动网络，提供比较基准，形成群体规范

#### 3. 教师智能体（制度性环境）

-   **特征**: 提供评价反馈，分配机会和任务
-   **角色**: 班主任、数学老师、英语老师、校长、图书管理员

### 🧠 动态人格系统（事件驱动）

**核心设计**: 事件触发更新，个体差异乘数，20%边界保护。

**可调整特质**: - **p_base**: 离开阈值（对环境平均奖赏的估计） - **eta_s**: 初始奖赏感知权重 - **eta_a**: 衰减率感知权重 - **beta_effort**: 努力敏感性（核心差异参数） - **daily_depression_level**: 当日抑郁水平

**更新规则**:

| 事件类型 | 影响参数                     | 抑郁Agent | 健康Agent |
|----------|------------------------------|-----------|-----------|
| 任务成功 | beta_effort↓, p_base↑, 抑郁↓ | ×0.7      | ×1.2      |
| 任务失败 | beta_effort↑, p_base↓, 抑郁↑ | ×1.5      | ×0.8      |
| 积极社交 | 抑郁↓, eta_s↑                | ×0.7      | ×1.2      |
| 消极社交 | beta_effort↑, eta_a↑, 抑郁↑  | ×1.5      | ×0.8      |
| 教师表扬 | beta_effort↓, 抑郁↓          | ×0.7      | ×1.2      |
| 教师批评 | beta_effort↑, 抑郁↑          | ×1.5      | ×0.8      |

**边界保护**: 参数不能偏离基线超过20%

``` gdscript
new_value = clamp(value, baseline - 0.2, baseline + 0.2)
```

**更新触发**: 任务完成/失败、社交互动、教师评价、每日反思

------------------------------------------------------------------------

### 🌙 每日反思系统（LLM-based）

**核心设计**: 不同于固定规则触发，Agent通过LLM自主反思，动态判断调整方向和幅度。

**流程**: 1. **反思分析**: LLM分析当日记忆，识别情绪主题和关键事件 2. **参数调整决策**: LLM判断四项认知参数的调整方向（↑/↓/→）和严重程度（1-5） 3. **动态幅度计算**: 严重程度映射到基础幅度（1%→12%），乘以个体差异乘数 4. **PHQ-9完整评估**: LLM评估九项症状（0-3分），计算总分和等级 5. **更新与记录**: 更新抑郁水平，记录反思记忆

**调整幅度**: \| 严重程度 \| 基础幅度 \| 抑郁Agent(×1.5) \| 健康Agent(×0.8) \| \|---------\|---------\|----------------\|----------------\| \| 1（轻微） \| ±1% \| ±1.5% \| ±0.8% \| \| 2（轻度） \| ±3% \| ±4.5% \| ±2.4% \| \| 3（中度） \| ±5% \| ±7.5% \| ±4.0% \| \| 4（重度） \| ±8% \| ±12% \| ±6.4% \| \| 5（严重） \| ±12% \| ±18% \| ±9.6% \|

**PHQ-9九项症状**: 1. 对事物几乎没有兴趣或愉悦感 2. 感到沮丧、抑郁或绝望 3. 入睡困难、睡眠不安或睡眠过多 4. 感到疲倦或精力不足 5. 食欲不振或暴饮暴食 6. 觉得自己很失败或让自己或家人失望 7. 难以集中注意力 8. 动作或说话缓慢，或相反地烦躁不安 9. 有伤害自己或自杀的念头

**分数转换**: PHQ-9总分(0-27) → 抑郁水平(0-1) - 0-4分: 无抑郁 (0-0.15) - 5-9分: 轻度抑郁 (0.15-0.33) - 10-14分: 中度抑郁 (0.33-0.52) - 15-19分: 中重度抑郁 (0.52-0.70) - 20-27分: 重度抑郁 (0.70-1.0)

## 快速开始 {#快速开始}

### 方式1：使用本地LLM（推荐，无需API密钥）

#### 1. 安装Ollama

``` bash
# macOS
brew install ollama
brew services start ollama
```

#### 2. 下载模型

``` bash
ollama pull qwen2.5:1.5b
ollama list  # 验证
```

#### 3. 运行项目

1.  启动Godot编辑器
2.  导入项目（选择`project.godot`）
3.  按F6运行

### 方式2：使用云端API

1.  克隆项目
2.  在Godot中运行项目
3.  按ESC打开设置
4.  选择API提供商（OpenAI、Kimi等）
5.  输入API密钥

## 详细理论说明 {#详细理论说明}

### 情境参数（客观存在）

| 情境               | 初始收益率(S) | 衰减率(a) | 努力成本(E) | 适合活动 |
|--------------------|---------------|-----------|-------------|----------|
| 教室（主教学区）   | 0.5 (中)      | 0.7 (快)  | 0.8 (高)    | 课堂发言 |
| 教室（小组讨论区） | 0.7 (高)      | 0.3 (慢)  | 0.6 (中)    | 小组合作 |
| 食堂               | 0.8 (高)      | 0.3 (慢)  | 0.2 (低)    | 同伴互动 |
| 走廊               | 0.3 (低)      | 0.3 (慢)  | 0.2 (低)    | 偶遇互动 |
| 体育馆             | 0.8 (高)      | 0.7 (快)  | 0.8 (高)    | 体育活动 |

### 认知机制参数（个体差异）

| 参数             | 符号         | 健康Agent | 抑郁Agent | 功能                   |
|------------------|--------------|-----------|-----------|------------------------|
| 离开阈值         | ρ_base       | 0.5-0.6   | 0.3-0.4   | 对环境平均奖赏率的估计 |
| 初始奖赏感知权重 | η_s          | 0.5       | 0.4       | 对初始丰富度的敏感度   |
| 衰减率感知权重   | η_a          | 0.5       | 0.7       | 对奖赏衰减的敏感度     |
| 收益敏感性       | α            | 0.8       | 0.5-0.6   | 收益的非线性效用       |
| **努力敏感性**   | **β_effort** | **0.4**   | **0.8**   | **核心差异参数**       |

### 模拟流程

```         
Step 1: Agent进入情境
   └─> 携带先验信念（首次）或历史记忆（再次进入）

Step 2: 体验采样
   └─> 系统发放客观收益（所有Agent相同）
   └─> Agent感知收益（受η_s, η_a影响，个体差异）
   └─> 积累样本到经验缓存

Step 3: 贝叶斯更新（每N个样本）
   └─> 更新对S和a的后验信念
   └─> 估计不确定性

Step 4: 效用计算
   └─> 用感知参数计算预期收益
   └─> 非线性效用：U = G^α - β_effort × E
   └─> 个体差异在此体现

Step 5: 决策（MVT规则）
   └─> 使用理论公式计算最优停留时间T*
   └─> log(T) = log[ηS·log(S)] − log(ρbase) − βeffort·effort − ηa·log(a) + ε
   └─> 考虑不确定性调整
   └─> 决策：STAY / LEAVE / SWITCH

Step 6: 行为执行与反馈
   └─> 实际停留并获得收益
   └─> 更新记忆和情绪状态
   └─> 每日PHQ-9自评更新抑郁水平

Step 7: 长期演化
   └─> 认知机制参数根据反馈动态调整
   └─> 形成个体化的抑郁风险发展轨迹
```

### 预期成果

**行为层面**: - 抑郁Agent表现出：回避高努力情境、提前离开、社交退缩 - 健康Agent表现出：积极探索、合理停留、正常社交

**参数层面**: - 验证 β_effort 作为核心差异参数的预测力 - 追踪抑郁风险Agent的 α、η_s、η_a 变化轨迹

**应用价值**: - 为青少年抑郁早期识别提供行为指标 - 为干预策略设计提供理论依据 - 为校园心理健康教育提供模拟平台
