## 决策指令
根据以上信息，请决定你下一步的行动。

### 行动选择原则

**不需要移动的情况**：
- 如果你已经在目标Agent的中范围内，可以直接START_DIALOGUE
- 如果你已经在对话附近，可以直接JOIN_DIALOGUE
- 如果你已经在体育馆，可以直接START_SPORTS
- 如果你已经在图书馆/自习室，可以直接START_STUDY
- 如果你已经在对话中，可以直接EXIT_DIALOGUE

**需要移动的情况**：
- 如果你想和某个Agent对话，但不在他的中范围内 → MOVE_TO_RANGE
- 你想加入某个对话，但不在该中范围内 → MOVE_TO_RANGE
- 你想对同一中范围内的Agent说悄悄话 → MOVE_TO_RANGE（移动到贴身位置）

### 可选行动类型

1. **MOVE_TO_RANGE** - 移动到指定位置
   - 使用场景：
     a) 需要接近目标Agent（不在同一中范围）
     b) 想对同一中范围的Agent说悄悄话（需要移动到贴身位置）
     c) 想去某个特定场景
   - **输出格式（严格遵循）**：`1 目标名称`
     - `1` 是移动行动的固定编号
     - 一个空格
     - 目标名称：必须是场景精确名称或人物精确全名
   - **有效示例**：
     - `1 教室（主教学区）` - 移动到该场景
     - `1 小明` - 移动到小明附近
     - `1 小红` - 移动到小红附近
   - **无效示例**：
     - `1 教室` - 名称不完整
     - `1 去小明那里` - 包含多余文字
     - `移动到小明` - 缺少编号

2. **START_DIALOGUE** - 开始普通对话
   - 使用场景：已经在目标Agent的中范围内，想发起普通对话
   - 必需参数：target_id（目标Agent ID）
   - 注意：普通对话不需要移动，直接开始即可

3. **START_WHISPER** - 开始悄悄话（私密对话）
   - 使用场景：想和某个Agent进行私密对话，不让其他人听到
   - **规则**：
     - 如果和目标在同一中范围 → 必须先MOVE_TO_RANGE（移动到贴身位置）
     - 如果和目标不在同一中范围 → 先MOVE_TO_RANGE接近，再START_WHISPER
   - 必需参数：target_id（目标Agent ID）

4. **JOIN_DIALOGUE** - 加入已有对话
   - 使用场景：已经在某个对话的中范围内
   - 可选参数：target_id（对话ID或发起者ID）

5. **EXIT_DIALOGUE** - 退出当前对话
   - 使用场景：正在对话中，想退出

6. **START_SPORTS** - 开始体育活动
   - 使用场景：已经在体育馆内
   - 限制：仅限体育馆场景

7. **END_SPORTS** - 结束体育活动
   - 使用场景：正在进行体育活动

8. **START_STUDY** - 开始自习
   - 使用场景：已经在图书馆或自习室内
   - 限制：仅限图书馆、自习室场景

9. **END_STUDY** - 结束自习
   - 使用场景：正在进行自习

10. **WAIT** - 等待
    - 使用场景：暂时不需要行动

### 决策示例

**示例1：直接开始普通对话（无需移动）**
```json
{
    "action_type": "START_DIALOGUE",
    "target_id": "小明",
    "reasoning": "小明就在我的中范围内，我想和他讨论刚才的问题"
}
```

**示例2：对同一中范围的Agent说悄悄话（需要移动）**
```json
{
    "action_type": "MOVE_TO_RANGE",
    "target_id": "1 小红",
    "reasoning": "小红在我的中范围内，但我想和她私下说悄悄话，需要移动到贴身位置",
    "cached_step2": {
        "action_type": "START_WHISPER",
        "target_id": "小红"
    }
}
```

**示例3：先移动后对话（不同中范围）**
```json
{
    "action_type": "MOVE_TO_RANGE",
    "target_id": "1 教室（主教学区）",
    "reasoning": "我想去教室找小明，他应该在主教学区",
    "cached_step2": {
        "action_type": "START_DIALOGUE",
        "target_id": "小明"
    }
}
```

**示例4：直接开始自习（无需移动）**
```json
{
    "action_type": "START_STUDY",
    "reasoning": "我现在在图书馆，想开始自习"
}
```

### 输出格式

请按以下JSON格式输出你的决策：
{
    "action_type": "行动类型",
    "target_id": "目标ID（如适用，移动时必须使用'1 名称'格式）",
    "reasoning": "决策理由（简要说明为什么选择这个行动）",
    "cached_step2": {
        "action_type": "第二步行动类型（可选，仅当第一步是MOVE_TO_RANGE时使用）",
        "target_id": "第二步目标ID（可选）"
    }
}

### 重要提醒

- **移动输出格式（必须严格遵守）**：`1 目标名称`
  - 编号`1` + 一个空格 + 精确名称
  - 名称必须是场景全名或人物全名
  - 不要添加任何其他文字或标点

- **普通对话 vs 悄悄话**：
  - 普通对话：同一中范围直接开始，无需移动
  - 悄悄话：即使是同一中范围，也需要先MOVE_TO_RANGE到贴身位置

- **优先选择不需要移动的行动**：如果当前位置已经可以执行目标行动（普通对话），不要浪费一步去移动

- **检查当前时段约束**：上课时间不能随意离开或开始对话

- **考虑你的人格特质**：外向者更可能主动开始对话，内向者可能选择等待

- **利用感知信息**：如果你感知到附近有有趣的对话，可以考虑加入
