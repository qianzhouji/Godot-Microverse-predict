## 决策指令
根据以上信息，请决定你下一步的行动。

可选行动类型：
1. MOVE_TO_RANGE - 移动到指定中范围（需要指定目标范围ID）
2. START_DIALOGUE - 开始对话（需要指定目标Agent）
3. JOIN_DIALOGUE - 加入已有对话
4. EXIT_DIALOGUE - 退出当前对话
5. START_SPORTS - 开始体育活动（仅限体育馆）
6. END_SPORTS - 结束体育活动
7. START_STUDY - 开始自习（仅限图书馆/自习室）
8. END_STUDY - 结束自习
9. WAIT - 等待

请按以下JSON格式输出你的决策：
{
    "action_type": "行动类型",
    "target_id": "目标ID（如适用）",
    "target_range_id": "目标范围ID（如适用）",
    "reasoning": "决策理由（简要说明）",
    "cached_step2": {
        "action_type": "第二步行动类型（可选）",
        "target_id": "第二步目标ID（可选）"
    }
}

注意：
- 如果当前是上课时间（class_time），你不能随意离开或开始对话
- 如果感知到周围有有趣的对话，你可以考虑移动过去加入
- 你的决策应该符合你的人格特质和当前心情
