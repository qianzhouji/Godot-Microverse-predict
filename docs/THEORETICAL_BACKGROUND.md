## 研究问题

### 核心问题

**抑郁风险学生是否在努力导向决策中存在系统性认知偏差？**

### 具体研究问题

1. **努力敏感性偏差**: 抑郁风险学生是否对努力成本过度敏感？
2. **奖赏感知偏差**: 抑郁风险学生是否对奖赏衰减感知异常？
3. **行为后果**: 这些认知偏差如何影响其情境选择和社交行为？

### 研究意义

- **理论意义**: 验证努力决策理论在青少年抑郁研究中的适用性
- **临床意义**: 为青少年抑郁早期识别提供行为指标
- **干预意义**: 为认知行为干预策略设计提供理论依据

## 边际价值定理 (MVT)

### 定理来源

**边际价值定理 (Marginal Value Theorem, MVT)** 由 Charnov (1976) 提出，最初用于解释动物觅食行为中的最优停留时间决策。

### 核心思想

Agent 应该在**边际收益等于边际成本**时离开当前情境：

```
离开时机：当瞬时收益率 = 平均环境收益率
```

### 数学模型

#### 1. 客观收益函数（系统层维护，Agent不可见）

```
G(t) = (S/a)[1 - exp(-at)]
```

| 参数 | 符号 | 说明 |
|------|------|------|
| S | 初始收益率 | 情境刚开始时的收益获取速率 |
| a | 收益衰减率 | 收益随时间衰减的速度 |
| t | 停留时间 | 在情境中停留的时间 |
| G(t) | 累积收益 | 停留t时间后获得的总收益 |

**函数特性**:
- 收益增长随时间递减（边际收益递减）
- 当 t → ∞ 时，G(t) → S/a（收益饱和）

#### 2. Agent感知与决策

**效用函数**:
```
U(G) = G^α - β_effort × E
```

| 参数 | 符号 | 健康Agent | 抑郁Agent | 说明 |
|------|------|----------|----------|------|
| α | 收益敏感性 | 0.8 | 0.5-0.6 | 收益的非线性效用 |
| β_effort | 努力敏感性 | 0.4 | **0.8** | 努力成本对效用的影响 |
| E | 努力成本 | - | - | 情境的客观努力要求 |

**最优停留时间**:
```
T* = argmax_T [(Ĝ(T)^α - β_effort × E) / (T + d)]
```

其中 d 是切换成本，Ĝ 是感知收益。

### 停留时间预测公式

基于层次贝叶斯模型，停留时间的对数线性预测：

```
log(T) = log[η_s · log(S) − log(ρ_base) − β_effort · effort] − η_a · log(a) + ε
```

| 参数 | 符号 | 说明 |
|------|------|------|
| ρ_base | 离开阈值 | 对环境平均奖赏率的估计 |
| η_s | 初始奖赏感知权重 | 根据情境初始丰富度调节停留时间 |
| η_a | 衰减率感知权重 | 感知奖赏消耗速度的准确性 |
| β_effort | 努力敏感性 | 努力成本对离开阈值的调节 |
| ε | 噪声项 | 决策噪声 |

## 努力决策理论

### 理论核心

**努力决策理论 (Effort-Based Decision Making)** 认为：

> 个体在决策时会权衡**预期收益**与**所需努力**，当主观努力成本超过主观收益时，会选择回避。

### 抑郁与努力决策

**核心假设**: 抑郁风险个体存在**动机性快感缺失 (Motivational Anhedonia)**

```
健康个体:  高努力 → 高奖赏 → 高动机 → 积极参与
抑郁个体:  高努力 → (预期)低奖赏 → 低动机 → 回避行为
                      ↑
                 认知偏差：
                 - 高估努力成本 (β_effort ↑)
                 - 低估奖赏价值 (α ↓)
                 - 悲观预期 (η_s ↓, η_a ↑)
```

### 四类核心参数

| 参数 | 符号 | 功能 | 抑郁风险特征 |
|------|------|------|-------------|
| **离开阈值** | ρ_base | 对环境平均奖赏的估计 | 偏低（悲观） |
| **初始奖赏感知权重** | η_s | 对情境初始丰富度的敏感度 | 异常 |
| **衰减率感知权重** | η_a | 对奖赏衰减速度的感知 | 偏高（高估衰减） |
| **努力敏感性** | β_effort | 努力成本对决策的影响 | **显著偏高** |

## 三层认知架构

### 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 1: 客观现实（系统层）                                  │
│  - 物理存在，所有Agent共享相同客观参数                         │
│  - 内容: 真实情境参数 (S, a, E)、真实收益函数                   │
│  - 访问: Agent不可见，通过RewardSystem间接获取奖赏             │
└─────────────────────────────────────────────────────────────┘
                              ↓
                    【通过RewardSystem发放】
                    （Agent只接收"奖赏"数值）
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 2: 感知推断（认知层）                                  │
│  - 贝叶斯更新过程，个体差异显著                                │
│  - 机制: 先验信念 → 体验采样 → 贝叶斯更新 → 后验信念            │
│  - 噪声: 感知噪声极小 (σ=2%)，主要噪声在决策层                  │
└─────────────────────────────────────────────────────────────┘
                              ↓
                    【感知参数影响决策】
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 3: 效用评估（决策层）                                  │
│  - 非线性效用计算，个体差异核心体现                            │
│  - 公式: U(G) = G^α - β_effort × E                           │
│  - 结果: 计算最优停留时间T*，驱动行为决策                        │
└─────────────────────────────────────────────────────────────┘
```

### 分层意义

1. **客观层隔离**: 确保Agent不能直接"偷看"系统参数，必须通过体验学习
2. **感知层个性化**: 不同Agent对同一情境有不同主观感知
3. **决策层差异化**: 核心个体差异（β_effort）在此层体现

## 抑郁风险的认知机制

### 健康 vs 抑郁风险 Agent 对比

| 认知机制 | 健康Agent | 抑郁风险Agent | 行为表现 |
|---------|----------|--------------|---------|
| **努力敏感性 β_effort** | 0.4 | **0.8** | 回避高努力情境 |
| **收益敏感性 α** | 0.8 | 0.5-0.6 | 奖赏效用降低 |
| **离开阈值 ρ_base** | 0.5-0.6 | 0.3-0.4 | 容易提前离开 |
| **初始感知权重 η_s** | 0.5-0.7 | 0.6 | 对初始印象异常敏感 |
| **衰减感知权重 η_a** | 0.4-0.55 | 0.7-0.75 | 高估奖赏衰减 |

### 行为预测

**抑郁风险Agent的行为特征**:

1. **回避高努力情境**
   - 课堂发言（高努力）→ 低优先级
   - 体育活动（高努力）→ 回避或提前离开
   - 食堂/走廊（低努力）→ 偏好

2. **提前离开**
   - 由于 ρ_base 偏低，容易满足
   - 停留时间 T* 较短

3. **社交退缩**
   - 社交互动需要努力
   - β_effort 高 → 社交回避

4. **悲观预期**
   - η_a 高 → 预期奖赏快速衰减
   - 缺乏持续参与的动力

### 情境设计依据

| 情境 | S | a | E | 适合研究 |
|------|---|---|---|---------|
| 课堂发言 | 中 | 快 | 高 | 努力回避 |
| 同伴互动 | 高 | 慢 | 低 | 社交行为 |
| 体育活动 | 高 | 快 | 高 | 双重回避 |

## 模型验证框架

### 验证层次

```
1. 行为机制验证
   └─ 抑郁Agent是否表现出更高的努力回避？
   
2. 抑郁症状轨迹验证
   └─ 模拟的PHQ-9轨迹是否与真实数据一致？
   
3. 临床转化风险验证
   └─ ROC/AUC分析，识别抑郁风险的准确率
   
4. 蒙特卡洛稳健性检验
   └─ 参数扰动下模型是否稳定？
```

### 预期成果

**行为层面**:
- 抑郁Agent：回避高努力情境、提前离开、社交退缩
- 健康Agent：积极探索、合理停留、正常社交

**参数层面**:
- 验证 β_effort 作为核心差异参数的预测力
- 追踪抑郁风险Agent的 α、η_s、η_a 变化轨迹

**应用价值**:
- 为青少年抑郁早期识别提供行为指标
- 为干预策略设计提供理论依据
- 为校园心理健康教育提供模拟平台

## 理论创新点

### 1. 计算模型与临床问题的结合

将 **MVT** 和 **努力决策理论** 应用于青少年抑郁研究，建立从认知机制到行为表现的计算桥梁。

### 2. 三层认知架构

创新性地将客观现实、感知推断、效用评估分离，实现：
- 系统层的可控性
- 感知层的个性化
- 决策层的差异化

### 3. 动态参数演化

不仅建模静态差异，还建模参数随经验的动态变化：
- 任务成功/失败 → 更新 β_effort
- 社交互动 → 更新 η_s、η_a
- 每日反思 → 更新抑郁水平

### 4. 多Agent交互模拟

通过13个Agent（2抑郁风险 + 6健康 + 5教师）的交互，模拟真实校园社会环境。

### 5. 可验证的预测

模型产生可验证的行为预测：
- 停留时间分布差异
- 社交互动频率差异
- PHQ-9轨迹演化
